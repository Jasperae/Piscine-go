🎯 TopDimensions Design System

1. 🎨 Color Palette

Color Purpose Hex
Midnight Blue Trust, professionalism, stability #1F2A44
Electric Teal Innovation, freshness, tech-forward #00C2B2
Soft Sand Warmth, friendliness, approachability #F5E9DC
Cloud White Simplicity, clarity, openness #FFFFFF
Slate Gray Neutral balance, legibility #6B7280

Midnight Blue for headers and navigation
Electric Teal for accents and CTAs
Soft Sand for backgrounds and cards
Cloud White for clean layouts.

2. 🖋️ Typography

Type Font Usage
Primary Inter or Satoshi Clean, modern sans-serif for body and UI
Secondary Playfair Display or DM Serif Elegant serif for headlines and brand statements
Accent Space Grotesk or Poppins Optional for tech-forward or playful moments

Keep font sizes readable and spacing generous. Use bold sparingly to emphasize hierarchy without overwhelming.

3. 🧩 UI Components

Buttons

  • Primary: Rounded corners, bold text, teal background, white text
  • Secondary: Outline style, soft sand background, midnight blue text
  • Hover States: Gentle shadow or slight color shift for tactile feel

Cards

  • Soft sand background with subtle shadows
  • Rounded edges for warmth
  • Clear hierarchy: icon/image → title → description → CTA

Forms

  • Minimal fields with clear labels
  • Generous padding and spacing
  • Microcopy for guidance (e.g., “We’ll never spam you.”)

4. 🪞Visual Style

  • Imagery: Use real, diverse small business owners in action — warm lighting, candid moments
  • Icons: Rounded, friendly line icons (e.g., Feather Icons or Phosphor)
  • Illustrations: Optional — flat, minimal, with soft curves and pastel tones
  • Motion: Subtle transitions and hover effects — no flashy animations

5. 🧠 Brand Personality in Design

Trait Design Translation
Professional Structured layouts, consistent spacing, clear typography
Innovative Use of modern UI patterns, teal accents, dynamic CTAs
Simple & Warm Soft backgrounds, rounded shapes, friendly microcopy

6. 📱 Responsive Behavior

  • Mobile-first design
  • Sticky headers with collapsible menus
  • Cards stack vertically with generous spacing
  • CTA buttons remain prominent and thumb-friendly
